# testprojet

Ce dépôt regroupe des supports de formation à Git et plusieurs archives de projets destinées à des exercices pratiques.

## Contenu du dépôt

### 1. Supports de formation Git

- `Formation Git - Basique-octo.pdf` : support de formation Git de niveau basique au format PDF.
- `Formation Git - Avance-octo.pdf` : support de formation Git avancée au format PDF.
- `Formation Git - basique.pptx` : présentation PowerPoint de la formation Git basique.
- `Formation Git - avancée.pptx` : présentation PowerPoint de la formation Git avancée.

### 2. Archives de projets et d'exercices

- `page-web-participative-master.tar.gz` : archive d'un projet de page web participative.
- `page-web-participative-rebase-master.tar.gz` : variante associée aux exercices de rebase Git.
- `page-web-participative-rebase-conflict-master.tar.gz` : variante destinée à un scénario de conflit lors d'un rebase.
- `repodistant-master.tar.gz` : archive d'un projet intitulé `repodistant`.
- `template_java-master.tar.gz` : archive d'un modèle de projet Java.

Le contenu détaillé de ces archives reste à examiner pour identifier précisément les fichiers et les exercices qu'elles contiennent.

### 3. Autres fichiers

- `LICENSE` : fichier contenant les informations relatives à la licence du dépôt.
- `README.md` : documentation initiale du dépôt.

## Utilisation

1. Consultez le support PDF ou PowerPoint correspondant à votre niveau.
2. Téléchargez l'archive correspondant à l'exercice souhaité.
3. Extrayez les fichiers dans un répertoire de travail.
4. Suivez les consignes de formation pour pratiquer les commandes Git.
5. Pour les exercices de rebase, travaillez sur la variante appropriée et observez les éventuels conflits.

## Technologies et thèmes abordés

- Git et la gestion de versions.
- Les opérations de rebase et la résolution de conflits.
- Les projets web participatifs.
- Les modèles de projets Java.

Cette liste présente les thèmes suggérés par les noms des fichiers ; les fonctionnalités exactes restent à confirmer par l'inspection des archives.
